Features

What's New

Performance

Memory limiter, RAM cleaner, and crash handler auto-close. Keep Roblox running smooth.

Cursors

Shift-lock themes with live preview. Custom cursor sets, arrows, and death sounds.

Looks

Femboy theme — yes, you read that right also please dont use it if you just woke up. 8-bit bootstrapper icon, and full UI customization.

Control

FastFlag editor with profiles, process priority, multi-instance, and Discord RPC.
