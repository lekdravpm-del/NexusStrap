Getting Started

Nexus Strap is a lightweight Roblox bootstrapper. It replaces the default Roblox launcher with a faster, more customizable alternative.

Installation

  • Download the latest release from GitHub or the homepage
  • Run NexusStrap.exe
  • The app will guide you through the initial setup
  • Log in with your Roblox account when prompted

First Launch

On first launch, Nexus Strap will set up its mod directory and apply default settings. You can customize everything later from the settings menu.

Note: Nexus Strap stores its files in %LOCALAPPDATA%\NexusStrap. Your settings are preserved across updates.

Features

Memory Limiter

Cap Roblox's memory usage to prevent it from eating all your RAM. Set a maximum in MB and Nexus Strap will enforce it.

RAM Cleaner

Periodically cleans up Roblox's memory footprint while the game is running. Works automatically in the background.

Crash Handler Auto-Close

Kills the Roblox Crash Handler process automatically to free up system resources.

Discord Rich Presence

Shows what page or dialog you're currently on in Nexus Strap via Discord's activity status.

Game Shortcuts

Create one-click shortcuts to launch specific Roblox games directly.

Process Priority

Set Roblox's process priority (Idle, Below Normal, Normal, Above Normal, High, RealTime) from within Nexus Strap.

Cursors

Shift-Lock Themes

Choose from a collection of shift-lock cursor themes. Each theme includes a custom MouseLockedCursor that replaces Roblox's default circle.

  • Preview each theme before applying
  • Themes are written to the correct Roblox textures folder automatically
  • Cursors are downscaled to Roblox's native 32x32 size

Custom Cursor Sets

Create, import, and export your own cursor packs. A cursor set includes:

  • MouseLockedCursor.png — The shift-lock cursor (32x32)
  • ArrowCursor.png — Standard mouse cursor (64x64)
  • ArrowFarCursor.png — Far-away cursor (64x64)
  • IBeamCursor.png — Text selection cursor (64x64)

Custom Death Sounds

Replace Roblox's default death sound with any OGG audio file.

FastFlags

What are FastFlags?

FastFlags are internal Roblox settings that control rendering, networking, and other engine behavior. Nexus Strap provides a visual editor to modify them safely.

Using the Editor

  • Browse the built-in flag list or search by name
  • Use presets for common configurations (performance, rendering, etc.)
  • Create and save your own flag profiles
  • Undo/redo support for all changes

Profiles

Save different flag configurations and switch between them. Useful if you want different settings for different games.

Settings

Appearance

  • Change the bootstrapper theme (includes Femboy theme)
  • Custom 8-bit bootstrapper icon
  • Dark and light mode support

Integrations

  • Add custom pre-launch integrations
  • Auto-close integrations after Roblox starts
  • Discord RPC toggle

Import / Export

Back up all your settings to a file and restore them on another machine. Covers FastFlags, mods, cursors, and preferences.

FAQ

Is Nexus Strap safe to use?

Yes. Nexus Strap is an open-source bootstrapper. It does not inject code into Roblox or modify game memory. It only changes the launcher and cosmetic files.

Will I get banned?

Nexus Strap does not modify Roblox's executable or memory. The FastFlag editor warns you about risky flags. Cosmetic mods (cursors, sounds) are not flagged by Roblox's detection.

Where are my settings stored?

In %LOCALAPPDATA%\NexusStrap. This includes your mod files, logs, and configuration.

How do I uninstall?

Use the built-in uninstaller from the settings menu, or manually delete the NexusStrap folder from AppData and remove the registry entry.

Can I contribute?

The project is open source on GitHub. Fork the repo, make your changes, and submit a pull request.
